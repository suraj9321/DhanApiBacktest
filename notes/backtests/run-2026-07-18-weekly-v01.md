# Backtest: weekly_v01 — first full 5y run

Part of [[Home]] · engine per [[architecture-backtester]] · config `configs/weekly_v01.yaml` · ledgers `data/backtest_weekly_v01_*.parquet`.

**Config:** T−1 09:20 entry, 15Δ iron condor, wings 200(put)/250(call), gate vrp_week ≥ 0, target 50%, stop 2×, delta-breach 0.35, hard exit expiry 13:15, risk 2.5%/trade, 5-min evaluation. Capital ₹8L. Aug 2021 – Jul 2026.

![[backtest-weekly_v01.png]]

## Result: NEGATIVE — does not survive costs

| Metric | Value |
|---|---|
| Total return | **−3.72%** (5y) |
| Sharpe | −0.68 · MaxDD −5.33% |
| Trades | 202 · Win rate 57.9% |
| Avg win / loss | +1,112 / −1,415 |
| Profit factor | 1.08 (≈ coin flip pre-cost) |
| **Costs** | **₹53,392 = 41% of gross wins** |
| Exits | target 116 · delta_breach 85 · stop 1 |

Gross P&L ≈ +₹23.6k; costs −₹53.4k → net −₹29.8k. Engine invariants passed; 2 smoke trades verified by hand earlier.

## Diagnosis

1. **Cost drag dominates.** 8 legs/trade × 202 trades on ~45 pts credit: fixed costs are huge relative to a 15Δ condor's thin capture. The +16 pts/wk edge in [[analysis-monday-entry]] was measured on the **ATM straddle**; the 15Δ condor keeps ~¼ of that edge while paying the same per-trade costs.
2. **delta_breach 0.35 fires on 42% of trades** (avg −1,415) — far too twitchy against 0.15Δ shorts; it *is* the loss engine. The formal stop (2×) fired once in 5 years.
3. Win rate 58% at ~0.8 win/loss ratio ⇒ expectancy ≈ 0 before costs.

## Next experiments (grid)

- **Iron fly variant** — ATM shorts + wings is the bounded version of the structure that actually carried the measured edge. Highest priority.
- Loosen/remove delta_breach (rely on stop_multiple); test breach ∈ {none, 0.45}.
- Tighter entry gate (vrp_z ≥ 0.5/1.0): fewer, better weeks — fewer cost events.
- Higher short delta (0.20/0.25): more credit per fixed cost.
- H2: twice-daily evaluation vs 5-min (whipsaw reduction).
